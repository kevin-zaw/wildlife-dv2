This repository contains a single-page data story titled "Millions of Eyes: Wildlife Observations in Australia," developed for FIT3179 Data Visualisation at Monash University. The project explores wildlife observations shared by the public via the Atlas of Living Australia and examines how citizen science feeds professional research. The visualization features 12 interactive charts, including multi-line charts, waffle charts, Marimekko charts, heatmaps, radial small multiples, and maps, built using Vega-Lite and Vega to communicate insights about animal distributions, seasonal behaviors, and reporting trends across Australia.
